Principles

A contract first, a runtime second.

The standard stays small and portable. Implementations compete underneath it.

API-first

CRDs, OpenAPI and provider protocols are versioned independently from implementation details.

Observe first

Missing evidence stays unknown. Mutation requires capability, policy, RBAC and identity authorization.

Replaceable providers

The reference runtime uses Kubernetes, Cilium and FRR, while the core contract remains provider-neutral.

Architecture

From raw signals to authorized change.

Each layer only depends on the contract below it, so any provider can be swapped.

ChangeControlled, policy-gated mutation with identity and RBAC checks.
AssessmentOptimality, stability and intervention impact scored from compatible evidence only.
EvidenceVersioned measurements, scoped and time-bound. Gaps are explicit.
ProvidersKubernetes, Cilium, FRR or your own, behind provider protocols.

A real fabric, published safely

The AdvFab Wiki turns the same evidence surfaces used by the Headlamp plugin into a public, privacy-preserving cluster snapshot. Infrastructure identifiers are domain-separated and SHA-256 hashed before publication.
